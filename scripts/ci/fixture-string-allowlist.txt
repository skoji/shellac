# Every string carried by the committed fixtures.
#
# audit-fixtures.sh asserts that each string in each fixture appears here,
# rather than scanning for particular strings that must be absent: fixtures
# must not carry author-identifying content, and only an allowlist can state
# that as a property of the file instead of as a list of things someone
# thought to look for. Because the check covers every string rather than a
# chosen set of keys, there is no encoding or dictionary position a value
# can occupy to avoid being listed here.
#
# Entries are values as reported by `qpdf --json`, which has already decoded
# the PDF-level encoding, keeping qpdf's type prefix:
#
#   u:  text. Written as plain text -- no backslash escapes, and a
#       parenthesis is just a parenthesis.
#   b:  bytes qpdf could not represent as text, hex-encoded. In this corpus
#       these are all trailer /ID values.
#
# Scope: strings in the document's object structure. Stream payloads are not
# strings and are covered by the other checks in audit-fixtures.sh (embedded
# filesystem paths, XMP identity properties); page text is deliberately out
# of scope, since the corpus exists to carry real book text.
#
# The fixtures are committed and frozen, so these values are fixed. Any
# regeneration changes the dates and /ID values (and, on a different
# toolchain, /Producer) and is expected to fail this audit until the new
# values are reviewed and added.
#
# Blank lines and lines starting with # are ignored.
